# 个人博客前端开发计划（静态页面版）

## 一、 项目初始化与基础配置 (高优先级)

1.  **初始化前端项目**: 在 `d:/projects/18.test-qoder-frontend/` 目录下，使用纯 HTML/CSS/JavaScript 静态页面来实现这个项目。
2.  **后端服务器**: 后端服务器能在 `http://localhost:8080` 上运行。
3.  **静态服务器**: 配置本地静态服务器，确保项目能在 `http://localhost:80` 上运行。
4.  **引入核心依赖**:
    - **路由管理**: 使用原生 JavaScript 实现 SPA 路由功能，或使用轻量级路由库如 `page.js`。
    - **状态管理**: 使用原生 JavaScript + localStorage/sessionStorage 来管理应用状态（如用户信息）。
    - **HTTP 客户端**: 使用原生 `fetch` API 或引入轻量级的 `axios` CDN 版本进行 API 交互。
    - **UI 组件**: 使用原生 CSS + JavaScript 实现 UI 组件，或引入轻量级 CSS 框架如 `Bootstrap` 或 `Tailwind CSS`。
    - **Markdown 处理**: 引入 `marked.js` 或 `markdown-it` CDN 版本用于 Markdown 解析和渲染。
5.  **基础配置**:
    - 创建统一的 API 请求工具函数，处理认证和错误。
    - 使用原生 JavaScript 管理全局状态和主题切换。
    - 实现全局错误处理和加载状态管理。

## 二、 用户模块 (中优先级)

1.  **注册与登录**:
    - 创建注册页面，包含用户名、密码、确认密码和邮箱输入框，添加表单验证（用户名长度、密码强度、邮箱格式、确认密码一致性等，防止无效数据提交和提升用户体验）。
    - 创建登录页面，包含用户名和密码输入框，添加表单验证（必填项检查、格式验证等）。
    - **认证机制**: 后端使用 Session 认证，前端通过 Cookie 自动管理会话状态。
    - 实现登录状态检查：应用启动时调用 `GET /api/users/profile` 验证当前登录状态。
    - 添加登录/注册的加载状态和错误提示。
2.  **用户信息展示与更新**:
    - 创建用户个人资料页面，用于展示用户的详细信息（昵称、邮箱、头像等）。
    - 实现用户信息更新功能，包含表单验证和成功提示。
    - 实现修改密码功能，包含旧密码验证和确认密码验证。
    - 添加头像上传功能（调用文件上传接口）。
3.  **导航守卫与权限控制**:
    - 配置路由守卫，对需要认证的页面进行访问控制。
    - 实现角色权限检查，区分普通用户和管理员权限。
    - 添加未登录用户访问受保护页面时的重定向逻辑。

## 三、 文章模块 (高优先级)

1.  **文章列表与分页**:
    - 创建首页或文章列表页，调用 `GET /api/articles` 接口获取文章列表。
    - 实现分页功能，支持页码跳转和页面大小设置。
    - **分类筛选**: 先调用 `GET /api/categories` 获取分类列表，在前端实现分类筛选（后端接口待完善）。
    - 添加文章搜索功能（按标题搜索）。
    - 实现文章列表的加载状态和空状态处理。
2.  **文章详情**:
    - 创建文章详情页，支持通过文章 ID 和版本号访问。
    - **两步加载机制**:
      - 第一步：调用 `GET /api/articles/:id/:version` 获取文章元数据（包含 `store_id`）。
      - 第二步：根据 `store_id` 调用 `GET /api/files/download/{file_id}` 下载文章内容。
    - 实现 Markdown 内容渲染，支持代码高亮和数学公式。
    - 添加文章阅读进度条和目录导航。
    - 实现文章分享功能和阅读量统计。

## 四、 通用功能 (高优先级)

1.  **全局布局**:
    - 设计并实现响应式的全局布局，包括统一的导航栏和页脚。
    - 实现暗色/亮色主题切换功能。
    - 添加面包屑导航和页面标题管理。
2.  **动态导航栏**:
    - 根据用户的登录状态，动态显示不同的菜单项。
    - 登录用户显示：用户头像、个人资料、注销按钮。
    - 未登录用户显示：登录、注册按钮。
    - 管理员用户额外显示："后台管理"入口。
3.  **全局状态管理**:
    - 实现用户登录状态的全局管理和持久化。
    - 实现用户注销功能，清理本地状态。
    - 添加会话过期检测和自动刷新机制。
4.  **错误处理与用户体验**:
    - 实现全局错误处理，统一显示错误信息。
    - 添加全局加载指示器和骨架屏。
    - 实现消息提示系统（成功、警告、错误提示）。
    - 添加网络异常和服务器错误的友好提示页面。

## 五、 管理员后台 (中优先级)

1.  **后台布局与导航**:
    - 为管理员功能区创建独立的布局和侧边栏导航。
    - 实现后台仪表板，显示文章统计、用户统计等概览信息。
2.  **文章管理页面**:
    - 创建文章管理列表页，支持搜索、筛选、批量操作。
    - 实现文章的新建、编辑、删除、发布/下架功能。
    - **文章编辑器功能**:
      - 使用 SimpleMDE 或 EasyMDE（轻量级 Markdown 编辑器，通过 CDN 引入）。
      - 实现实时预览和全屏编辑模式。
      - **图片处理流程**:
        - 使用正则表达式识别 Markdown 中的本地图片链接（`![](./path/to/image.ext)`）。
        - 在识别到的图片链接旁添加"上传"按钮（原生 JavaScript 实现）。
        - 用户点击上传按钮，选择对应图片文件。
        - 调用 `POST /api/files/upload` 上传图片。
        - 上传成功后，自动替换为服务器地址：`![](http://localhost:port/api/files/download/{file_id})`。
      - **文章发布流程**:
        - 第一步：处理完图片后，将整个 Markdown 内容作为文件上传，获取 `store_id`。
        - 第二步：调用 `POST /api/articles` 提交文章元数据（标题、描述、分类、标签、store_id）。
    - 使用 localStorage 实现文章草稿保存功能。
3.  **分类和标签管理**:
    - 实现分类的增删改查功能。
    - 实现标签的管理和自动补全功能。
4.  **权限控制与安全**:
    - 为所有管理员路由添加权限守卫，检查用户角色是否为 `admin`。
    - 非管理员用户访问后台时，重定向到 403 错误页面。
    - 实现操作日志记录（可选）。

## 七、 UI 设计风格指导

**现代化苹果风格设计原则**:

- **极简主义**: 去除不必要的装饰元素，专注于内容本身
- **大量留白**: 合理运用空白空间，营造清爽、透气的视觉效果
- **圆角设计**: 按钮、卡片、输入框等元素采用适度圆角（8-12px），柔和亲和
- **毛玻璃效果**: 导航栏、模态框等使用半透明毛玻璃背景（backdrop-filter: blur()）
- **微妙阴影**: 使用柔和的阴影效果增加层次感，避免过重的边框
- **优雅动画**: 页面切换、按钮交互使用流畅的缓动动画（ease-out, 300ms）
- **系统字体**: 优先使用系统默认字体栈（-apple-system, BlinkMacSystemFont, 'Segoe UI'）

**色彩方案**:

- **主色调**:
  - **经典灰色系**（推荐）: 深空灰（#1D1D1F）配合银色强调（#8E8E93）
- **背景色**: 纯白色（#FFFFFF）配合极浅灰色（#F2F2F7）
- **文字色**: 深灰色层次（#000000, #3C3C43, #8E8E93）
- **暗色模式**: 深色背景（#000000, #1C1C1E）配合高对比度文字

**布局特点**:

- **卡片式设计**: 内容区域使用圆角卡片，增强信息层次
- **居中对齐**: 重要内容居中展示，左右留白
- **网格系统**: 使用 12 列响应式网格，保持视觉平衡
- **导航简洁**: 顶部导航栏透明或半透明，图标简洁明了

## 八、 技术选型建议

**推荐技术栈（静态页面）**:

- **核心技术**: HTML5 + CSS3 + 原生 JavaScript (ES6+)
- **构建工具**: 无需复杂构建工具，使用简单的静态文件服务器
- **路由**: 使用 `page.js` 或原生 `history API` 实现 SPA 路由
- **状态管理**: 原生 JavaScript + localStorage/sessionStorage
- **UI 框架**: Bootstrap 5 或 Tailwind CSS（通过 CDN 引入）
- **HTTP 客户端**: 原生 fetch API 或 axios CDN 版本
- **Markdown 处理**: marked.js 或 markdown-it（通过 CDN 引入）
- **代码高亮**: highlight.js（通过 CDN 引入）
- **样式**: 原生 CSS3 + CSS 变量（支持主题切换）
- **动画**: CSS3 transitions/animations + 适量的原生 JavaScript
- **图标**: Font Awesome 或 Feather Icons（通过 CDN 引入）

## 十、 开发注意事项

1.  **API 调用规范**:

    - 所有 API 调用都要添加错误处理和加载状态。
    - 创建统一的 API 工具函数，封装 fetch 请求，处理认证和错误。
    - 实现请求重试机制（网络异常时）。
    - 使用 Promise + async/await 语法确保代码可读性。

2.  **用户体验优化**:

    - 使用 CSS 实现骨架屏和加载动画。
    - 使用原生 JavaScript 实现无限滚动（长列表）。
    - 使用原生 JavaScript 实现模态框和确认对话框。
    - 确保页面在低配置设备上的流畅性。

3.  **安全考虑**:

    - 对用户输入进行 XSS 防护。
    - 实现 CSRF 保护（如果需要）。
    - 敏感操作添加二次确认。

4.  **响应式设计**:

    - 确保在移动设备上的良好体验。
    - 实现适配不同屏幕尺寸的布局。

5.  **苹果风格实现细节**:

    - 使用 CSS 变量和原生 JavaScript 管理主题色彩，支持亮色/暗色模式切换。
    - 实现毛玻璃效果：`backdrop-filter: saturate(180%) blur(20px)`。
    - 按钮悬停效果：轻微缩放（transform: scale(0.98)）和透明度变化。
    - 页面切换动画：使用 CSS3 transitions 实现淡入淡出配合轻微位移效果。
    - 加载状态：使用 CSS3 keyframes 实现苹果风格的旋转指示器。

6.  **静态页面开发注意事项**:
    - 合理组织文件结构，分离 HTML、CSS、JavaScript 代码。
    - 使用模块化的 JavaScript 代码，避免全局变量污染。
    - 优化资源加载，合理使用 CDN 资源。
    - 确保代码在各种浏览器中的兼容性。
    - 使用原生 JavaScript 替代复杂框架，保持代码轻量化。
