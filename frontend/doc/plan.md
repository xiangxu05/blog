# 个人博客前端开发计划

## 一、 项目初始化与基础配置 (高优先级)
1.  **初始化前端项目**: 在 `/d:/projects/personal_blog/web/` 目录下，使用现代前端框架（推荐 Vue.js，学习曲线平缓）初始化项目。
2.  **后端服务器**: 后端服务器能在 `http://localhost:8080` 上运行。
3.  **配置路由**: 配置路由，确保项目能在 `http://localhost:80` 上运行。
3.  **引入核心依赖**:
    *   **路由管理**: 安装并配置 `vue-router` (Vue) 或 `react-router` (React) 用于页面导航。
    *   **状态管理**: 安装并配置 `Pinia` (Vue) 或 `Redux` (React) 来集中管理应用状态（如用户信息）。
    *   **HTTP客户端**: 安装并配置 `axios` 用于与后端API进行交互。
    *   **UI组件库**: 推荐使用 `Element Plus` (Vue) 或 `Ant Design` (React) 提升开发效率。
    *   **Markdown编辑器**: 安装 `@toast-ui/editor` 或 `vditor` 用于文章编辑功能。
4.  **基础配置**:
    *   配置 `axios` 请求/响应拦截器，统一处理认证和错误。
    *   设置环境变量管理（开发/生产环境的API地址）。
    *   配置全局错误处理和加载状态管理。

## 二、 用户模块 (中优先级)
1.  **注册与登录**:
     *   创建注册页面，包含用户名、密码、确认密码和邮箱输入框，添加表单验证（用户名长度、密码强度、邮箱格式、确认密码一致性等，防止无效数据提交和提升用户体验）。
     *   创建登录页面，包含用户名和密码输入框，添加表单验证（必填项检查、格式验证等）。
    *   **认证机制**: 后端使用Session认证，前端通过Cookie自动管理会话状态。
    *   实现登录状态检查：应用启动时调用 `GET /api/users/profile` 验证当前登录状态。
    *   添加登录/注册的加载状态和错误提示。
2.  **用户信息展示与更新**:
    *   创建用户个人资料页面，用于展示用户的详细信息（昵称、邮箱、头像等）。
    *   实现用户信息更新功能，包含表单验证和成功提示。
    *   实现修改密码功能，包含旧密码验证和确认密码验证。
    *   添加头像上传功能（调用文件上传接口）。
3.  **导航守卫与权限控制**:
    *   配置路由守卫，对需要认证的页面进行访问控制。
    *   实现角色权限检查，区分普通用户和管理员权限。
    *   添加未登录用户访问受保护页面时的重定向逻辑。

## 三、 文章模块 (高优先级)
1.  **文章列表与分页**:
    *   创建首页或文章列表页，调用 `GET /api/articles` 接口获取文章列表。
    *   实现分页功能，支持页码跳转和页面大小设置。
    *   **分类筛选**: 先调用 `GET /api/categories` 获取分类列表，在前端实现分类筛选（后端接口待完善）。
    *   添加文章搜索功能（按标题搜索）。
    *   实现文章列表的加载状态和空状态处理。
2.  **文章详情**:
    *   创建文章详情页，支持通过文章ID和版本号访问。
    *   **两步加载机制**:
        *   第一步：调用 `GET /api/articles/:id/:version` 获取文章元数据（包含 `store_id`）。
        *   第二步：根据 `store_id` 调用 `GET /api/files/download/{file_id}` 下载文章内容。
    *   实现Markdown内容渲染，支持代码高亮和数学公式。
    *   添加文章阅读进度条和目录导航。
    *   实现文章分享功能和阅读量统计。

    *   创建文章管理列表页，支持搜索、筛选、批量操作。
    *   实现文章的新建、编辑、删除、发布/下架功能。
    *   **文章编辑器功能**:
        *   集成专业的Markdown编辑器（推荐 `@toast-ui/editor`）。
        *   实现实时预览和全屏编辑模式。
        *   **图片处理流程**:
            *   自动识别Markdown中的本地图片链接（正则匹配 `![](./path/to/image.ext)`）。
            *   在识别到的图片链接旁显示"上传"按钮。

            *   第一步：处理完图片后，将整个Markdown内容作为文件上传，获取 `store_id`。

4.  **权限控制与安全**:

## 七、 UI设计风格指导

**现代化苹果风格设计原则**:
- **极简主义**: 去除不必要的装饰元素，专注于内容本身
- **大量留白**: 合理运用空白空间，营造清爽、透气的视觉效果
- **圆角设计**: 按钮、卡片、输入框等元素采用适度圆角（8-12px），柔和亲和
- **毛玻璃效果**: 导航栏、模态框等使用半透明毛玻璃背景（backdrop-filter: blur()）
- **微妙阴影**: 使用柔和的阴影效果增加层次感，避免过重的边框
- **优雅动画**: 页面切换、按钮交互使用流畅的缓动动画（ease-out, 300ms）
- **系统字体**: 优先使用系统默认字体栈（-apple-system, BlinkMacSystemFont, 'Segoe UI'）

**色彩方案**:
- **主色调**: 
  - **经典灰色系**（推荐）: 深空灰（#1D1D1F）配合银色强调（#8E8E93）
- **背景色**: 纯白色（#FFFFFF）配合极浅灰色（#F2F2F7）
- **文字色**: 深灰色层次（#000000, #3C3C43, #8E8E93）
- **暗色模式**: 深色背景（#000000, #1C1C1E）配合高对比度文字

**布局特点**:
- **卡片式设计**: 内容区域使用圆角卡片，增强信息层次
- **居中对齐**: 重要内容居中展示，左右留白
- **网格系统**: 使用12列响应式网格，保持视觉平衡
- **导航简洁**: 顶部导航栏透明或半透明，图标简洁明了

## 八、 技术选型建议

**推荐技术栈（Vue.js）**:
- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **路由**: Vue Router 4
- **状态管理**: Pinia
- **UI组件库**: Element Plus（需自定义主题以符合苹果风格）
- **HTTP客户端**: Axios
- **Markdown编辑器**: @toast-ui/editor
- **代码高亮**: highlight.js
- **样式**: SCSS + CSS Modules
- **动画库**: @vueuse/motion 或 Framer Motion（实现流畅过渡效果）
- **图标**: SF Symbols 风格图标库或 Heroicons

## 九、 开发注意事项

1.  **API调用规范**:
    *   所有API调用都要添加错误处理和加载状态。
    *   统一使用axios拦截器处理认证和错误。
    *   实现请求重试机制（网络异常时）。

2.  **用户体验优化**:
    *   添加骨架屏提升加载体验。
    *   实现无限滚动或虚拟滚动（长列表）。
    *   添加操作确认对话框（删除等危险操作）。

3.  **安全考虑**:
    *   对用户输入进行XSS防护。
    *   实现CSRF保护（如果需要）。
    *   敏感操作添加二次确认。

4.  **响应式设计**:
     *   确保在移动设备上的良好体验。
     *   实现适配不同屏幕尺寸的布局。

5.  **苹果风格实现细节**:
     *   使用CSS变量管理主题色彩，支持亮色/暗色模式切换。
     *   实现毛玻璃效果：`backdrop-filter: saturate(180%) blur(20px)`。
     *   按钮悬停效果：轻微缩放（transform: scale(0.98)）和透明度变化。
     *   页面切换动画：使用淡入淡出配合轻微位移效果。
     *   加载状态：使用苹果风格的旋转指示器，而非传统进度条。
